Edge AI Hardware Platform

A low-power edge AI hardware platform for running vision ML/DL models and small language models entirely on-device, targeting 5 field pilots: smart cities, water/stormwater monitoring, bushfire detection, smart transportation, and healthcare.

  • Evaluated edge compute platforms (NVIDIA Jetson Orin Nano 8GB, Raspberry Pi 5 + Hailo-8L, Rockchip RK3588, Intel N-series) against power envelope, NPU throughput, and PyTorch/ONNX deployment criteria for off-grid solar vs mains-powered profiles
  • Designed a model compression pipeline: knowledge distillation (YOLOv8m/l → YOLOv8n-class student), exported via PyTorch → ONNX → OpenVINO, quantised to INT8 with NNCF, benchmarked for latency/accuracy tradeoffs across CPU and iGPU
  • Synthesized a 10-phase execution plan (Hardware, Software, Business & Admin tracks) from architecture through field pilot deployment
  • Produced hardware spec sheets, risk register, and solar/battery power budget calculations for cross-functional team alignment

Tech: ONNX, OpenVINO, NNCF, PyTorch, Intel NUC

Agentic AI Assistant

An agentic AI education assistant with a capybara persona — evolved from a RAG chatbot into a tool-calling agent that exposes its retrieval and evaluation capabilities as MCP (Model Context Protocol) tools, making AI/ML concepts engaging and accessible for high school students (ages 14–18) across 8 core topics.

  • Built a custom Python MCP server exposing hybrid BM25 + dense retrieval, CrossEncoder reranking, and fun-fact generation as callable tools, so any MCP-compatible client can query the knowledge base directly
  • Agentic tool-calling loop lets the LLM decide when to invoke retrieval vs. reason directly vs. generate a fun fact, replacing a fixed retrieve-then-generate pipeline; structured JSON responses (answer, emotion, fun_fact) designed for a future video/audio avatar integration layer
  • LLM-as-Judge evaluation framework with self + cross-model judging and Cohen's kappa scoring vs human annotators
  • Query rewriting, few-shot prompted generation via Groq API; local inference pipeline via Ollama
  • Persona tuned for teen relatability: capybara humor, sparse slang, platform-relevant analogies (For You page, Discord, gaming)

Tech: Python, MCP (Model Context Protocol), BM25, FAISS, Ollama, Groq API, CrossEncoder, LLM-as-Judge, Cohen's kappa, FastAPI

ASX Equity Forecasting

Cross-sectional return forecasting across ASX 50 using a 260-feature panel (245K+ samples, 2005–2026). Selected LightGBM after diagnosing deep learning generalisation failures. Test IC = +0.054, ICIR = +0.314, annualised L/S Sharpe = +0.429. Resolved T4 GPU OOM in TFT by redesigning to a VSN-free linear encoder, reducing GPU memory ~6×.

Tech: Python · LightGBM · PyTorch · TFT · PySpark
